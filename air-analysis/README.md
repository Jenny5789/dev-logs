# 서울 대기오염 데이터 분석 (EDA)

> **질문** 서울역 앞 한강대로의 대기오염은 평일과 주말, 시간대에 따라 실제로 얼마나 달라질까?

> **답** 평일 PM2.5가 주말보다 1.7 ug/m³ 높았고, 낮 12시에 최고(18.0 ug/m³), 22시에 최저(11.0 ug/m³)를 기록했다. 분석 기간 전반적으로 기준치 이하를 유지했다.

서울 용산구 한강대로 측정소의 7일치 대기환경기준물질 6종 데이터로 EDA를 수행한 프로젝트

## 프로젝트 구성

```
01 시계열 추이 ──▶ 02 평일/주말 비교 ──▶ 03 상관관계 ──▶ 04 시간대 패턴 ──▶ 05 O3-NO2 관계
```

| 단계 | 내용 |
|------|------|
| 01 시계열 추이 | 6개 항목의 1시간 단위 변화, 기준선 함께 표시 |
| 02 평일/주말 비교 | PM2.5 박스플롯으로 요일 패턴 비교 |
| 03 상관관계 분석 | 히트맵 + 산점도로 오염물질 간 관계 확인 |
| 04 시간대 패턴 | 0~23시 PM2.5 평균으로 하루 중 변화 파악 |
| 05 O3-NO2 관계 | 이중 Y축 그래프로 두 물질의 시간별 관계 탐색 |

---

## 주요 발견

### 1. 분석 기간 전반적으로 기준치 이하 유지

- PM2.5 평균 14.2 ug/m³, 좋음 수준 (24시간 기준: 35 ug/m³)
- 모든 항목이 분석 기간 내 환경기준 초과 없음
- 05/19 전후로 PM10, PM2.5, NO2, CO, SO2가 동시에 상승하는 경향 관찰
- SO2는 05/19 구간에서 일시적으로 급등 후 급감

### 2. 평일 PM2.5가 주말보다 소폭 높음

| 구분 | PM2.5 평균 |
|------|-----------|
| 평일 | 14.6 ug/m³ |
| 주말 | 12.9 ug/m³ |
| 차이 | 1.7 ug/m³ |

차이가 예상보다 작은 것은 서울역 특성상 평일·주말 모두 대중교통 중심 이동지라 차량 배출가스 영향이 제한적이었던 것으로 추정

### 3. PM2.5와 연소·교통 관련 물질 간 양의 상관관계

| 물질 쌍 | 상관계수 | 해석 |
|---------|---------|------|
| PM10 ↔ PM2.5 | r = 0.84 | 강한 양의 상관 |
| PM2.5 ↔ SO2 | r = 0.71 | 강한 양의 상관 |
| PM2.5 ↔ CO | r = 0.65 | 강한 양의 상관 |
| PM2.5 ↔ NO2 | r = 0.50 | 중간 수준 양의 상관 |
| O3 ↔ NO2 | r = -0.15 | 약한 음의 상관, 뚜렷한 연관성 없음 |

### 4. PM2.5는 낮 시간대에 높고 야간에 낮음

| 시간대 | PM2.5 평균 | 특징 |
|--------|-----------|------|
| 12시 | 18.0 ug/m³ | 최고 |
| 7~9시 | 소폭 상승 | 출근 시간대 |
| 22시 | 11.0 ug/m³ | 최저 |

## 측정 항목

대기환경보전법 기반 6가지 기준물질

| 항목 | 단위 | 환경기준 | 특징 |
|------|------|---------|------|

## 분석 기준 상세

**기준선 설정**
- 시계열 시각화에 각 항목의 환경기준치를 기준선으로 표시
- 기준 초과 여부를 분석 전반에 걸쳐 명시적으로 확인

**그룹 분류**
- 평일: 월~금, 주말: 토~일로 구분
- 7일 데이터라 주말 데이터는 2일(48개 레코드)에 불과

**상관관계 해석**
- 피어슨 상관계수 사용
- 단기 데이터라 통계적 유의성은 낮으며 탐색적 해석에 그침

## 한계

- 7일치 단기 데이터로 통계적 유의성 낮음; 주말 데이터가 2일뿐이라 평일/주말 비교는 참고 수준
- 기상 데이터(풍속, 강수, 기온) 없어 05/19 전후 농도 변화의 원인을 직접 검증 불가
- 교통량 데이터 없어 차량 배출가스 영향을 정량화할 수 없음
- 단일 측정소 데이터라 서울 전체 경향으로 일반화 불가
- 분석 후반부 농도 감소가 강수 세정 효과와 연관될 가능성이 있으나 확인 불가

## 회고

단기 시계열 데이터로 EDA의 전형적인 분석 흐름(추이 → 그룹 비교 → 상관관계 → 패턴)을 직접 수행했다.

과정에서 체감한 점:
- 기준선을 시각화에 함께 표시하면 수치의 맥락을 파악하기 훨씬 쉬워짐
- 단기 데이터에서 나온 패턴은 경향의 확인보다 가설 설정에 더 적합하다는 것을 인식
- O3-NO2 관계처럼 기대와 다른 결과가 나왔을 때, 데이터 한계인지 실제 현상인지 구분하는 것이 중요
