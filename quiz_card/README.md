## ✨ 주요 기능

- 📚 단어장 생성 / 수정 / 삭제
- 🃏 카드 추가 / 수정 / 삭제 / 드래그 순서 변경
- 🔍 단어장 및 카드 검색
- 🎴 카드 뒤집기 학습 (애니메이션)
- ✅ 맞춤 / 틀림 체크 및 진행도 표시
- 🏆 결과 화면 (정답률, 틀린 카드 Top 10)
- 🔄 오답 카드 복습 기능
- 💾 학습 진행상태 저장 및 이어서 하기
- 🎨 테마 색상 3종 변경 (제주 밭 / 제주 바다 / 한라 노을)
- 📝 폰트 크기 조절
- 🗺️ 온보딩 화면 (첫 실행 시)

## 📖 사용 방법

### 1️⃣ 단어장 만들기
1. 홈 화면에서 **단어장 목록** 버튼 클릭
2. 우측 하단 **+** 버튼 클릭
3. 단어장 이름 입력 후 **추가** 클릭

### 2️⃣ 카드 추가하기
1. 단어장 목록에서 원하는 단어장 클릭
2. 우측 하단 **+** 버튼 클릭
3. 앞면(질문/단어)과 뒷면(답/뜻) 입력 후 **추가** 클릭

### 3️⃣ 학습하기
1. 카드 목록 하단 **학습 시작** 버튼 클릭
2. 카드를 **탭**해서 뒤집기
3. 맞으면 **맞춤**, 틀리면 **틀림** 버튼 클릭
4. 학습 도중 나가면 **이어서 하기** 가능

### 4️⃣ 결과 확인하기
1. 학습 완료 후 정답률 확인
2. 틀린 카드 **Top 10** 확인
3. **틀린 카드 다시 보기**로 오답 복습

### 5️⃣ 설정
1. 홈 화면 우측 상단 **⚙️** 버튼 클릭
2. 테마 색상 / 폰트 크기 / 학습 방향 변경
3. **설정 저장** 버튼 클릭
